# 우리봇v1

[우리봇v2](https://github.com/steve94458/woori-botv2)의 전 버전. 마인크래프트 커뮤니티 서버용 디스코드 경제·도박 봇이다.
TypeScript(discord.js v14)로 만들었고, 봇 상태를 보는 웹 대시보드(React + Vite)가 같이 들어 있다.

> 지금은 쓰지 않는 버전이다. 새 기능은 v2에만 들어간다.

---

## 기능

명령어 전체 목록은 봇에서 `!명령어`로 볼 수 있다.

### 🏦 은행·대출
돈은 은행 계좌에 들어간다. 은행 3곳은 예금·대출 이율이 서로 다르다.

| 명령 | 설명 |
|---|---|
| `!은행` · `!은행 가입 [1/2/3]` · `!은행 목록` | 계좌 정보, 은행별 이율, 계좌 개설 |
| `!출석` | 하루 한 번 1만 원 (계좌로 입금) |
| `!돈` | 계좌 잔액과 BTC 보유량 |
| `!이체 [내계좌] [상대계좌] [금액]` · `!내계좌이체` | 송금 |
| `!대출 신청/상환/일괄상환` | 은행을 골라 대출, 다른 은행 계좌로도 받을 수 있다 |
| `!상점` | 칭호 같은 아이템 |

### 🎰 도박·게임
금액과 계좌 번호를 붙여서 건다.

| 명령 | 설명 |
|---|---|
| `!도박` | 50% 확률 |
| `!블랙잭` | 딜러와 블랙잭 |
| `!포커` | 비디오 포커 (로열 플러시 250배) |
| `!슬롯머신` · `!룰렛` · `!홀짝` | 슬롯머신, 룰렛(초록 14배), 주사위 홀짝 |
| `!경마` | 말 4마리 중 하나에 건다 (4배) |
| `!크래시` | 올라가는 배수가 터지기 전에 목표 배수 맞히기 |
| `!로또` | 1~9 중 숫자 3개 맞히기 (최대 100배) |
| `!야추` | 12턴 야추 다이스 |
| `!가위바위보` · `!주사위배틀` | 봇이나 다른 유저와 대결 |
| `!도박취소` | 진행 중인 게임을 끝내고 돌려받기 |

### ⛏️ BTC 채굴
- `!채굴 상점` · `구매` · `판매` · `현황` · `슬롯확장`
- 채굴기를 사서 BTC를 캐고, `!채굴 정산`으로 원화로 바꾼다 (1 BTC = 1억 원).

### 📈 주식
- `!주식` 시세 · `!주식 그래프 [코드]`(최근 15번 변동) · `!매수` · `!매도` · `!내주식`
- `!주식알림 켜기/끄기 [코드]` — 주가가 변하면 알림

### 🛡️ 관리자
- 주식 추가·제거, 시세 변동 시간·범위 설정, 주가 조작, 초기화 값·시간
- 이자·채굴 주기, 돈 지급·압류, 강제 매도, 파산, 명령어 채널 설정

### 🖥️ 웹 대시보드
- 봇 연결 상태와 로그를 보고, 토큰으로 직접 다시 로그인할 수 있다.

## 파일 구조
```
server.ts             봇 본체 + 웹 서버 (Express). 명령어·게임·은행·주식·채굴 전부 여기
src/                  웹 대시보드 (React)
index.html            대시보드 진입 페이지
vite.config.ts        대시보드 빌드 설정
ecosystem.config.cjs  pm2 실행 설정
README_RPI.md         라즈베리파이 설치 가이드
check_db.js · copy_db.js · check_env.js · test_bigint.js · refactor*.ts   개발 중에 쓴 보조 스크립트
```
데이터는 `.data/economy.db`(SQLite, better-sqlite3)에 저장된다. 처음 켜면 알아서 만든다.

## 설치와 실행

필요한 것: Node.js 18 이상, 디스코드 봇 토큰

```bash
npm install
cp .env.example .env      # 값 채우기
npm run build             # 웹 대시보드 빌드
npm start                 # 봇 + 웹 서버 (포트 3000)
```

pm2로 계속 켜 두기:
```bash
pm2 start ecosystem.config.cjs
```
라즈베리파이에서 처음부터 설치하는 방법은 [`README_RPI.md`](README_RPI.md).

### 환경 변수 (`.env`)
| 키 | 설명 |
|---|---|
| `DISCORD_TOKEN` | 디스코드 봇 토큰 |
| `VITE_BASE_PATH` | 웹 대시보드를 하위 경로에 올릴 때 (예: `/bot/`). 비우면 `/` |
| `GEMINI_API_KEY` · `APP_URL` | 처음 만든 Google AI Studio 템플릿에서 온 값. 지금 코드에선 거의 안 쓴다 |
| `PORT` | 참고용. 서버는 코드에서 3000번 포트로 고정 |

비밀값은 `.env`에서만 읽는다. `.env`와 `.data/`는 저장소에 올라가지 않는다.
